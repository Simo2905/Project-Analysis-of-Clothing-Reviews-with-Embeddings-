# Project-Analysis-of-Clothing-Reviews-with-Embeddings-
The project aims to demonstrate in practice how to use text embeddings and Python to analyze reviews in the “womens_clothing_e-commerce_reviews.csv” dataset in order to understand customer opinions. This analysis will help improve customer service and product offerings. (by DataCamp)

This is a practical project inside the "Associate AI Engineer for Developers" course provided by Datacamp
